Для котировок используется Yahoo Finance chart endpoint. Для макроэкономики — официальный FRED API. FRED требует персональный 32-символьный API key. Ключ сохраняется в localStorage этого браузера.

Получить ключ можно через аккаунт FRED. Не публикуй его в GitHub или в открытом коде.
